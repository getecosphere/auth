# Auth LXS integration guide

Read this before composing `auth`. This source repository is the authority for
the binary contract; consumers receive the released binary and `docs/` bundle.

## Compose safely

Add the published binary with `eco lxs add auth@<version>` from an estate. Do
not copy Auth source into an estate. Compose it with `gateway` and `auth-ui`:

```yaml
services:
  auth-backend:
    lxs: auth@<version>
    access:
      routes:
        - { path: /api/auth/login, level: public }
        - { path: /api/auth/register, level: public }
        - { path: /api/auth/forgot-password, level: public }
        - { path: /api/auth/reset-password, level: public }
        - { path: /api/auth/*, level: auth }
        - { path: /auth-api/auth/login, level: public, strip: /auth-api, rewrite: /api }
        - { path: /auth-api/auth/register, level: public, strip: /auth-api, rewrite: /api }
        - { path: /auth-api/auth/forgot-password, level: public, strip: /auth-api, rewrite: /api }
        - { path: /auth-api/auth/reset-password, level: public, strip: /auth-api, rewrite: /api }
        - { path: /auth-api/*, level: auth, strip: /auth-api, rewrite: /api }
```

The `JWT_SECRET`, `MONGODB_URI`, port, CORS origins, roles, and public email
origin are generated by Eco/configgen. Never hand-copy a JWT secret or write a
production `.env`.

## Session and recovery contract

`auth-ui` writes both `localStorage.eco_session` and the `eco_token` cookie.
Every SSR page protected by gateway must declare `level: auth` and
`cookie: eco_token`; APIs use `Authorization: Bearer <token>`. Logout must call
`POST /auth-api/auth/logout`, clear both stores, and navigate to `/`.

Forgot-password and reset-password are public routes. The former always
returns 202; never tell users whether an email exists. Password recovery is an
email credential flow, and resets revoke all active sessions.

## Ownership

Auth owns credentials, identity (`name`, username, email, role), JWTs and
sessions. `profile` owns bio and avatar; compose `storage` with profile for
avatar upload. A business core owns its own user data and authorization rules.

## Release discipline

Keep `docs/` and this guide in sync with code. Run Rust checks, build Darwin
and Linux artifacts, publish with `eco lxs publish`, then push the source repo
and registry commit/tag. All stdout logging remains NDJSON.
